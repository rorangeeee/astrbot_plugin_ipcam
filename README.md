# AstrBot IPCAM 插件
基于AstrBot方式实现对rtsp视频流的图像截取和视频捕获。

## 已实现
- ✅ 图像捕获（支持质量和尺寸调整）
- ✅ 视频捕获（支持多种编码格式）
- ✅ 视频流连通性测试
- ✅ 超时处理和错误处理
- ✅ 自动清理本地文件
- ✅ **WebUI 配置页面**（全新功能！）

## WebUI 配置页面

插件提供了美观的 WebUI 配置页面，可以在线配置所有参数。

### 访问方式
在 AstrBot 管理面板中，找到 IPCAM 插件，点击"配置"或直接访问 `/ipcam` 路由。

### 配置选项

#### 基础配置
- **视频流地址 (RTSP URL)**: 输入你的网络摄像头 RTSP 地址
- **连接超时**: 视频流连接超时时间（秒）
- **读取超时**: 视频流读取超时时间（秒）

#### 视频配置
- **默认录制时长**: 录制视频的默认时长（秒）
- **视频编码格式**: 选择视频编码格式（推荐 MP4V）

#### 图片配置
- **图片质量**: JPEG 压缩质量（1-100）
- **图片宽度**: 调整图片宽度，0 表示保持原始尺寸

#### 高级选项
- **自动清理文件**: 发送后自动删除本地文件
- **启用日志**: 记录详细操作日志

### 功能特点
- 🎨 美观的渐变色设计
- 📱 响应式布局，支持移动端
- 🔍 实时连接测试功能
- 💾 配置持久化保存
- ⏪ 配置重置功能

## 命令使用

### 命令列表
- `/cap_img` - 捕获当前图像并发送
- `/cap_vid` - 录制视频（使用配置的默认时长）并发送

### 使用示例
1. 确保已配置正确的 RTSP 视频流地址
2. 发送 `/cap_img` 获取当前画面
3. 发送 `/cap_vid` 录制并发送视频

### 视频捕获修复
- 使用 mp4v (H.264) 编码替代 XVID
- 添加编码器自动回退机制
- 添加超时和错误处理
- 添加文件生成验证
- 修复资源泄漏问题

### 图像捕获优化
- 支持 JPEG 质量调整
- 支持图片尺寸调整
- 使用唯一文件名避免冲突
- 自动资源释放

### 配置管理系统
- JSON 格式配置文件（`ipcam_config.json`）
- 默认参数自动初始化
- 支持在线修改和保存

## 安装说明

1. 将插件文件夹复制到 AstrBot 插件目录
2. 重启 AstrBot
3. 在管理面板中配置视频流地址
4. 开始使用！

## 配置文件

插件会生成 `ipcam_config.json` 配置文件，包含所有可配置参数：

```json
{
    "stream_url": "rtsp://192.168.1.4:8554/live",
    "connection_timeout": 5,
    "read_timeout": 5,
    "video_duration": 10,
    "video_codec": "mp4v",
    "image_quality": 90,
    "image_width": 0,
    "auto_cleanup": true,
    "enable_logging": true
}
```

## 注意事项

- 确保 RTSP 视频流可访问
- 录制视频会占用临时存储空间
- 建议启用自动清理功能
- MP4V 编码兼容性最好
